## 🛒 PosSelect 쇼핑몰 (MSA & Micro Frontends)

풀스택 마이크로서비스 및 마이크로 프론트엔드(MFE) 아키텍처 기반의 쇼핑몰을 설계·구축하고 있습니다.

- **마이크로 프론트엔드(MFE) 아키텍처**: `shell`, `ui`(공통 디자인 시스템), `customer`, `product`, `admin`, `store` 등 독립된 프론트엔드 레포지토리로 분리하여 런타임 통합 구조 구축
- **Storybook 기반 UI 문서화 및 테스트 자동화**: `posselect-ui` 디자인 시스템을 구축하고 `play` 함수 기반의 컴포넌트 자동화 테스트 및 시각적 검증 환경 연동
- **백엔드 서비스 분리 및 게이트웨이 통합**: `product`, `customer` 등 도메인 단위 API 서비스 분리 후, K3s Ingress 및 Gateway를 통해 단일 진입점으로 트래픽 라우팅
- **보안 및 인증 고도화**: JWT 기반 토큰 직접 검증 아키텍처 구현 및 Supabase 도입을 통한 통합 인증(SSO)과 데이터 동기화 인프라 검토
- **AI-Driven Development 체계 구축**: 복잡한 MFE 환경을 제어하기 위해 레포지토리별 특화 Sub-agent 페르소나 및 자동 검수 룰(`AGENTS.md`) 도입
- **작업 및 이슈 트래킹**: 자가 호스팅 Redmine을 구축하여 체계적인 작업 이슈 발행 및 로그 관리

## 🏠 홈 인프라 & 네트워크 운영

개인 서버 인프라를 직접 구성하고 보안을 강화해 왔습니다.

- **네트워크 진입점 최소화**: 공유기(ASUS) WAN 노출 포트를 HTTP/HTTPS/SSH만 남기고 전부 정리, 불필요한 공격 표면 제거
- **동적 IP 대응**: DDNS로 외부에서 안정적으로 접근 가능한 도메인 운영
- **DNS/이메일 보안 강화**: Route 53으로 도메인 DNS 레코드를 관리하고, 사용하지 않는 이메일 발신 경로를 막기 위해 SPF `-all`, DMARC `reject` 정책으로 전환해 스푸핑 리스크 차단

## 🧭 일하는 방식

- 문제를 발견하면 임시방편보다 **근본 원인을 찾아 구조적으로 정리**하는 것을 선호합니다
- 인프라 변경은 되돌리기 어려운 작업이 많다는 것을 알기에, **작업 전 정리 → 단계적 전환 → 문서/이슈로 기록**하는 흐름을 지킵니다
- AI 도구(Claude Code)를 개발 파트너로 적극 활용해 아키텍처 설계, 리팩터링, 운영 자동화의 생산성을 높이고 있습니다
